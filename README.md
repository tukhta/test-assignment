# Проверка скорости скачивания

Небольшое веб-приложение на Node.js. Введите прямую ссылку на файл: сервер скачает его 10 раз подряд, а страница покажет среднее время запроса, общий размер ответов и скорость.

## Запуск

Нужен установленный Node.js. Дополнительные пакеты устанавливать не нужно.

В терминале перейдите в папку проекта и запусти сервер:

```bash
git clone https://github.com/tukhta/test-assignment.git
cd test-assignment
node server.js
```

Откройте в браузере `http://localhost:3000`. Чтобы остановить сервер, нажми `Ctrl+C` в терминале.

## Единицы измерения

Скорость выводится в Мбит/с: общий объём скачанных ответов переводится в биты и делится на полное время десяти загрузок. Объём показан в байтах.
